## 📖 Overview

**Keen Keeper** is a clean and intuitive task management application. Add, edit, and delete tasks with interactive components and charts for productivity tracking.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| ✅ **Add Tasks** | Create new tasks quickly |
| ✏️ **Edit Tasks** | Modify task details |
| 🗑️ **Delete Tasks** | Remove completed tasks |
| 📊 **Task Analytics** | Interactive charts (Recharts) |
| 📱 **Responsive** | Mobile & desktop |
| 🎨 **Clean UI** | DaisyUI components |
